# Скилл «Презентации ИдаПроджект»

Скилл для ИИ-агентов (Claude Code, Codex и других клиентов, которые читают папку `SKILL.md`). Он собирает и проверяет презентации в фирменном стиле ИдаПроджект: тёмные слайды 1920×1080 в Figma, один неоновый акцент, Aeonik Pro и JetBrains Mono, плоские карточки и чипы.

Тема, спикер и формат ТЗ могут быть любыми. Скилл отвечает за то, что от доклада к докладу не меняется: логику слайдов, композицию, визуальную систему и структуру колоды.

## Что умеет скилл

- Превращает ТЗ, сценарий или тезисы спикера в план колоды: главы, разделители, серии слайдов, кольцо из трёх тезисов.
- Подбирает тип каждому слайду из каталога. В нём 30 типов в 9 семействах, и для каждого описаны композиция, стили и типичная ошибка.
- Применяет цветовые и типографические стили. Шкала кеглей и интервалов кратна 4.
- Собирает слайды в Figma: клонирует готовые слайды из шаблона и свежих презентаций и наполняет их.
- Проверяет результат по шести критериям: композиция, типографика, общее восприятие, качество UI, понятность, узнаваемость бренда. Порог — 9 из 10 по каждому. Затем проверяет по 10 эвристикам Нильсена, и нарушений серьёзности 3–4 быть не должно.
- Общается с вами и пишет тексты слайдов на русском.

## Что нужно для работы

- Агент, который поддерживает скиллы: Claude Code, Codex или другой клиент с поддержкой `SKILL.md`.
- Подключённый Figma MCP, авторизованный под вашим аккаунтом Figma. Без него скилл может составить план колоды, но собрать слайды в Figma не сможет.
- Доступ на просмотр к двум файлам Figma, на которые опирается скилл:
  - шаблон слайдов «ИдаПроджект шаблоны»: https://www.figma.com/slides/yRNgBdeFmQR59BYGiiiDJL
  - готовые презентации «Презентации · Мероприятия»: https://www.figma.com/design/Xq7u4weQ5eKXuHdK0uqFYT
- Для установки через `npx` — Node.js 18 или новее.

## Как агент получает доступ к шаблонам и презентациям

Шаблоны и готовые презентации — закрытые файлы компании, поэтому в репозиторий они не входят. Агент открывает их напрямую через Figma MCP. MCP работает от вашего аккаунта Figma, так что агент видит ровно те файлы, к которым есть доступ у вас.

1. Подключите Figma MCP и войдите в Figma. В Claude Code это делается командой `/mcp` или в настройках коннекторов.
2. Откройте обе ссылки выше в браузере и проверьте, что они у вас открываются. Если нет — попросите доступ на просмотр у владельца файла.
3. Дальше агент сам изучает макеты шаблона и свежие презентации и клонирует подходящие слайды в ваш рабочий файл. Сами эталонные файлы он не меняет.

Если доступа нет, агент работает по описанию стиля из скилла и предупреждает в отчёте, что живые примеры не проверены.

## Установка

### Способ 1. Дать ссылку агенту

Отправьте агенту сообщение:

```
Установи скилл из https://github.com/cenya-ida/idaproject-presentations-skill
```

Агент прочитает [INSTALL.md](INSTALL.md), скопирует скилл в нужную папку и расскажет, что сделал.

### Способ 2. Через npx

В корне проекта выполните:

```bash
npx --yes github:cenya-ida/idaproject-presentations-skill
```

По умолчанию скилл ставится в `./.claude/skills/idaproject-presentations-skill`, это папка проекта для Claude Code. Опции:

| Опция | Куда ставится |
|---|---|
| без опций или `--claude` | `./.claude/skills` — Claude Code, текущий проект |
| `--agents` | `./.agents/skills` — Codex и проекты на AI OS |
| `--all` | в обе папки |
| `--global` | в домашнюю папку (`~/.claude/skills` или `~/.agents/skills`), скилл будет доступен во всех проектах |
| `--dir <путь>` | в указанную папку |
| `--force` | заменить уже установленную версию |
| `--dry-run` | показать, что произойдёт, ничего не записывая |

Например, поставить скилл глобально для Claude Code:

```bash
npx --yes github:cenya-ida/idaproject-presentations-skill --global
```

### Способ 3. Вручную

Скопируйте папку `skills/idaproject-presentations-skill` из репозитория в `.claude/skills/` или `.agents/skills/` вашего проекта.

После установки откройте новую сессию агента: скиллы подхватываются только при старте сессии.

## Как пользоваться

Вызовите скилл напрямую: `/idaproject-presentations-skill` в Claude Code или `$idaproject-presentations-skill` в Codex. Можно и просто описать задачу, тогда агент сам подключит скилл.

- «Собери презентацию по этому ТЗ, спикер — Иван Иванов, доклад на 40 минут»
- «Вот сценарий выступления, сначала покажи план колоды»
- «Пересобери слайд 12, он перегружен» и ссылка на фрейм в Figma
- «Проверь эту презентацию по критериям и эвристикам Нильсена»

Как агент работает по скиллу:
1. Разбирает вход и предлагает план колоды. Если вы не разрешили работать автономно, ждёт согласования.
2. Собирает слайды в Figma.
3. Проверяет результат и сам исправляет найденное.
4. Присылает отчёт: что изменено, какие тексты добавлены от себя, откуда взяты цифры, оценки по критериям и что осталось проверить вам.

Перед крупной переделкой агент делает копию слайда или страницы. Файлы Figma он правит только по вашему запросу.

## Обновление

Повторите установку с опцией `--force`:

```bash
npx --yes github:cenya-ida/idaproject-presentations-skill --force
```

Или попросите агента: «Обнови скилл idaproject-presentations-skill из репозитория». Локальные правки при этом перезапишутся.

Если вы ставили скилл раньше, когда он назывался `idaproject-slides`, удалите старую папку `.claude/skills/idaproject-slides` или `.agents/skills/idaproject-slides`. Иначе у агента окажутся две копии скилла.

## Состав репозитория

```
skills/idaproject-presentations-skill/
├── SKILL.md                    # порядок работы, принципы, планка качества
└── references/
    ├── narrative.md            # логика и структура колоды
    ├── slide-types.md          # каталог типов слайдов
    ├── visual-system.md        # сетка, цвета, типографика, компоненты
    ├── figma-build.md          # сборка через Figma MCP
    ├── review.md               # критерии оценки и эвристики Нильсена
    └── qa-checklist.md         # финальный чек-лист
bin/install.js                  # установщик для npx
INSTALL.md                      # инструкция по установке для агентов
```

Файлы скилла написаны на английском: так агенты понимают их надёжнее. При этом сам скилл требует общаться с пользователем и писать тексты слайдов на русском.
